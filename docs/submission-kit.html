Provenance: Verified Excel
provenance
Read Excel workbooks exactly, recalculate them with new inputs, and know which answers are verified against Excel's own results.
Provenance gives Claude exact access to Excel workbooks (.xlsx, .xlsm). Instead of eyeballing a spreadsheet, Claude reads every cell and formula, recalculates the workbook in Python with Excel's semantics, and reports which results are verified. - Inspect and find: sheets, values and formulas as a table; search for any label, number or formula. - Explain and trace: how a cell is calculated, what feeds it, what depends on it, and whether it is verified. - What-if: change input cells and get every affected result, before and after, without Excel. - Goal seek: find the input that makes a result hit a target ("what price gets profit to 10,000?"). - Sensitivity tables: one- or two-way data tables over ranges of inputs. - Compare: every changed value, formula and sheet between two versions of a workbook. - Convert and certify: lossless canonical JSON plus a Python module of every formula, with a certificate. Structure is proven by rebuilding the file, each formula is replayed against the result Excel stored, and the formulas are fuzz-tested against an independent engine. Formulas Provenance does not fully model are labelled unverified with the reason, never guessed, so Claude can tell you which numbers to trust. Give Claude a workbook by dropping it on the upload page (you get a file id to paste into your chat; the file is deleted after an hour) or by sharing a public https link (Google Sheets share links work). The hosted server handles typical workbooks (up to about 1 MB compressed); larger files run with the free local version. Nothing is kept after use.

Step 7 · Data handling

Own software; no third-party API. The server only fetches a URL the user supplies. Each workbook is processed in a short-lived sandboxed process and deleted when the call finishes; files on the upload page are deleted within one hour. No database, no cache across calls, no account data. Logs record time, status and duration only, never file contents, URLs or cell values. No health data, no sponsored content, nothing used for training.
